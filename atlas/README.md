# Palimpsesto Atlas

**Heritage Knowledge Observatory · Research prototype v0.33**

This directory publishes the source-linked research observatory developed by
Nina Monticelli / Nina Arquitetura. It is distinct from the earlier CHEDAR
concept prototype at the repository root.

## Entry points

- `index.html` opens the current Atlas release.
- `v0.33/index.html` is the versioned research prototype.
- `v0.33/release.json` records version, provenance and file checksums.

Both HTML entry points carry a `noindex` directive. They are not linked from
the existing site navigation. This is public hosting: `noindex` does not
provide authentication or prevent direct access, download or link sharing.

## Version and evidence

The published app preserves every script, dataset, diagram and logo from the
archived `Palimpsesto_v33.html`. The web copy changes only the description,
application-name metadata and robots directive. The archived original and
published-copy SHA-256 values are recorded in `v0.33/release.json`.

Maturity admits 13 publications / 14 applications with at least one supported
function level and accepted analytical source-access/review statuses.
The full embedded archive retains 14 publication dossiers / 15 applications,
including the excluded Theatro dossier, for provenance.

The prototype automatically applies selection and classification rules to
curated structured evidence. Article retrieval, PDF parsing and automatic
evidence extraction are not implemented. Coverage is partial and Maturity
profiles have not undergone independent scholarly validation.

The app is self-contained. Local assessment drafts use browser storage and
are specific to that browser and origin; hosting does not synchronize them.
The complete archival audit ZIP is preserved separately from this deployment.
