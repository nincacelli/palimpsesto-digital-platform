# Palimpsesto Digital Platform

Interactive frontend prototype for the **Palimpsesto Digital Lab** platform, a collaborative digital heritage ecosystem for metadata, maturity assessment, authorship recognition and international collaboration.

## Concept

Palimpsesto Digital Lab is designed to transform digital heritage assets into collaborative, citable and evolving knowledge systems.

The platform is not intended to become a heavy-file repository. Instead, it works as an intelligent metadata, maturity and collaboration layer over existing repositories, institutional servers and external digital archives.

## Prototype scope

This repository contains a conceptual frontend MVP developed for the **CHEDAR Challenge, Digital Ecosystems for Heritage 4.0**.

The current prototype uses simulated data and demonstrates the platform experience, including:

- global heritage dashboard;
- interactive world map with heritage assets;
- asset registry and asset cards;
- internal asset pages;
- maturity overview and gap diagnosis;
- collaborative calls;
- user registration prototype;
- asset registration prototype with image upload field;
- authorship, anteriority and contribution traceability;
- simulated validation and payment flow;
- simulated EIR-HBIM generator;
- knowledge resources and recent publications.

## Main principle

**From isolated files to living knowledge systems.**

The platform aims to make digital heritage assets findable, comparable, reusable, citable and continuously evolving.

## Current status

This is a frontend prototype for demonstration purposes. It does not yet include a backend, database, authentication, real upload, payment processing or persistent storage.

Future development may include:

- React or Next.js frontend;
- Supabase or PostgreSQL database;
- authentication and user roles;
- asset metadata submission workflow;
- external repository links for large-scale files;
- validation and certification process;
- collaborative call management;
- DOI or formal identifier integration;
- publication and peer-review layer.

## Disclaimer

This prototype was developed as a concept proposal for the CHEDAR Challenge. Visuals, people, assets and interface data are illustrative and may include AI-generated and graphic design resources. Depicted people are fictional and do not represent real individuals.
